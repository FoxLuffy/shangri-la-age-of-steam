# F2 — Replace datetime.utcnow() Deprecations Design

Roadmap item: **F2** (Housekeeping). `datetime.utcnow()` is deprecated (Python 3.12+); it
emits `DeprecationWarning` across the backend (19 sites in 8 files).

## Goal
Remove every `datetime.utcnow()` call from backend source with **identical output**, so no
timestamps or formats change.

## Helper: `backend/timeutils.py`
```python
from datetime import datetime, timezone

def utcnow() -> datetime:            # timezone-aware UTC
    return datetime.now(timezone.utc)

def utcnow_naive() -> datetime:      # naive UTC — drop-in for datetime.utcnow()
    return datetime.now(timezone.utc).replace(tzinfo=None)

def utc_iso() -> str:                # "YYYY-...Z" — byte-identical to the old output
    return utcnow_naive().isoformat() + "Z"
```

`utc_iso()` reproduces `datetime.utcnow().isoformat() + "Z"` exactly (naive isoformat has no
offset, so appending "Z" matches). `utcnow_naive()` matches the naive value the old default
factory produced for datetime columns.

## Replacements
- `datetime.utcnow().isoformat() + "Z"` → `utc_iso()`
  (main.py ×6, repository.py, admin.py, auth.py ×4, crafting.py, saves.py ×2)
- `datetime.utcnow().isoformat()` → `utcnow_naive().isoformat()` (gameplay.py ×2)
- `datetime.utcnow().strftime(...)` → `utcnow_naive().strftime(...)` (saves.py ×1)
- `default_factory=datetime.utcnow` → `default_factory=utcnow_naive` (models.py)

Each edited file imports from `backend.timeutils` and drops the now-unused `datetime`
import only if nothing else uses it.

## Tests: `backend/tests/test_timeutils.py`
- `utc_iso()` ends with `"Z"` and parses to an aware UTC datetime.
- `utcnow_naive()` has `tzinfo is None`.
- `utcnow()` has `tzinfo == timezone.utc`.
